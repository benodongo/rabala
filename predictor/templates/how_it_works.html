How a forecast is produced

From elder-elicited rules to a calibrated ensemble.

timeline

Pipeline

  1. 1

    Elicitation

    Wind, moon, cloud and felt-temperature cues gathered from fishing elders.

  2. 2

    Weather ingest

    Open-Meteo current + daily for the chosen lat/lon.

  3. 3

    Fuzzy inference

    87 Mamdani rules → Good / Normal / Risky / Bad.

  4. 4

    ML ensemble

    Random Forest + fuzzy posterior, calibrated cross-fit.

  5. 5

    Threshold decision

    Per-class thresholds via tune_thresholds.

  6. 6

    Logged

    Inputs, probabilities and model version stored for review.
